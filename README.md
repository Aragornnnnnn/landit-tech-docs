## 문서의 범위

2026-10-15에 비공개 BE·AI·IaC 저장소의 Wiki에서 관련 문서를 선별해 공개했다. 구현 저장소와 전체 Git 이력은 공개하지 않았다. 각 문서에 적힌 기준일, 원본 커밋, 검증 환경을 유지했다.

- 설계 문서는 해당 시점의 정책을 설명하며 현재 배포 상태를 보증하지 않는다.
- 코드 근거는 선택된 파일과 행의 발췌다. 생략 범위와 가린 운영 식별자를 표시했다.
- 로컬 테스트, 당시 운영 관측, 배포 상태를 서로 구분한다.
- 블로그의 과거 근거를 새 구현으로 덮어쓰지 않는다. 새 근거는 별도 커밋과 기준일로 추가한다.
